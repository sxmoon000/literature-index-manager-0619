# 📚 文献索引管理器

> 论文参考文献管理 — 自动分类、标签、BibTeX导出

## 🧠 知识点
- **自动分类**: 关键词库匹配 → 火箭回收/自适应控制/ML/NLP...
- **TF-IDF 关键词**: Counter 词频统计 + 停用词过滤
- **BibTeX 生成**: 纯 Python 实现 LaTeX 引用格式
- **去重**: key 唯一索引防止重复添加
- **多维搜索**: 标题/作者/年份/关键词/分类 自由组合

## 🚀 运行
```bash
python src/manager.py
```
